# 工作台需求与验收记录

本清单随工作台功能更新。设计依据见[工作台设计](zephyr-ide-workbench.zh-cn.md)，操作步骤见[使用手册](../../resources/workbench.zh-cn.md)，历史测量见[功能与布局评审](workbench-review.zh-cn.md)。

| 用户场景 | 交付约定 | 验收依据 |
| --- | --- | --- |
| 打开 Zephyr IDE | 工作台内切换工程、环境、设置；切换配置页复用编辑器 | 已有单面板工作台与双语使用手册 |
| 从本地工程开始 | 支持 west 与直接 CMake，显示官方变量、目录、板和 CPU；用户手填参数优先 | 两种方式切换保留草稿；选板不改写手工 BOARD、CONF_FILE |
| 离线与依赖 | 使用 Zephyr 工程与配置、west 清单版本和模块声明；组件支持本地路径，支持有网与离线 | 工作区和工程依赖测试；HC32F4A0 使用通用规则，覆盖多行及空白 |
| 模块清单 | 已选在上、候选在下；本地状态、目标版本、依赖来源与单项/批量获取可见；明暗主题沿用 VS Code 颜色 | 两种语言的清单、分页和本地 Git 下载验证 |
| 查找模块与滚动 | 搜索框、正则开关和匹配数就近属于候选区；内层到边界后滚轮可驱动外层 | 同一工作区在列表底部向下、顶部向上，两种语言实测 |
| 快捷操作 | 功能区标题栏图标常驻，尊重用户显式设置；图标带可访问名称 | Windows 中英文标题栏检查，鼠标移出区后仍可用 |
| 图上选型 | 在工程详情下显示应用、板/CPU、Kconfig、设备树的关系；双击节点选路，键盘可用，可搜索并拖动画布 | 用已安装扩展读取 mps2/an386 构建并选择板、Kconfig 符号和 UART 节点 |
| 隔离编辑 | 草稿按工程、构建目录和目标文件区分；Kconfig 增删查改，设备树标量及开关写入 overlay；预览后显式保存，遇到外部修改保留草稿 | 在临时工程验证保存、放弃、撤销与外部写入冲突；检查生成文件和原工程文件 |
| 大屏与独立窗口 | 内嵌、整页和独立 VS Code 窗口共用配置草稿，可聚焦和缩放；保留原页工作位置 | 分别验证打开、切换、共享草稿和返回 |
| 截图和教学 | Windows 显示模式和验收截图均为 1920 × 1080；双语教程与带指针、点击提示的动图同步 | 中英文共 8 个动图、2 张独立窗口原图；逐张核对 1920 × 1080。测试窗口支持独立捕获，本轮未验证系统锁屏状态 |
| 工程质量 | 命名和格式沿用上游；复用本地发现、Kconfig 与构建接口，避免机器绝对路径；按功能提交 | 编译、ESLint、离线测试、安装包与交互验证；记录实际测试平台 |
| 分支、归属与评审 | 单面板设计在 single-panel-configuration；保留上游版权和分叉记录。翻译和功能的上游申请与本地设计分支分别维护 | 推送和上游 CI 状态以各自远端记录为准 |
